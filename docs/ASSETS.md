# Website assets

Event photographs are illustrative and do not represent official event artwork or imply endorsement.

Images are served locally to keep the demonstration independent of image CDNs:

- `concert.jpg`: [original Unsplash image](https://images.unsplash.com/photo-1514525253161-7a46d19cd819), used for the feature image and Coldplay card.
- `eras.jpg`: [original Unsplash image](https://images.unsplash.com/photo-1501386761578-eac5c94b800a), used for the Taylor Swift card.
- `racing.jpg`: [Todd Jiang on Unsplash](https://unsplash.com/photos/formula-1-race-car-speeding-on-track-jLZzWgJtRXs), used for the motorsport card.

See the [Unsplash license](https://unsplash.com/license) for photograph terms. The ticket mark and interface icons are inline SVGs created for this project. The type stack uses system sans-serif fonts and Georgia.

SockJS 1.6.1 and STOMP.js 2.3.3 are vendored under `static/vendor/` with their original license files.
